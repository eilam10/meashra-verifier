Meashra Agent Verifier

Check an agent identity directly against the public registry. This page talks only to the RPC endpoint you choose. It calls no Meashra server, uses no account and no key of ours.

Any Sepolia RPC works. The default is a free public endpoint run by a third party. For extra assurance, run it again with a different provider and compare.
